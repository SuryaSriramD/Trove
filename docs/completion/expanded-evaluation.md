```sh
  --go-build-cache /absolute/disposable/go-cache \
  --bundle /absolute/verified/native-bundle \

```

Use `--family p0-holdouts` for the 12 closure holdouts and `--family modes` for all 42 held-out mode cases. Repeat `--case <fixture-id>` for a focused retry; the report explicitly sets `fullFamilyRun=false` and never counts that retry as a full-corpus pass. The macOS runner builds the test binary with offline Go resolution, denies networking through the OS sandbox during build/execution, omits ambient provider credentials, records source state and production/corpus/helper/model/binary/output digests, and checks unchanged inputs afterward. Output records split across Go log events are reassembled per test before accounting. Manifest replacement is atomic; at least 4 GiB of free space is required on both evidence and private temporary volumes before starting. This harness reserve is not a new product storage requirement. External scratch may hold build caches/evidence, but must not be presented as qualified private runtime storage. Missing/duplicate/skipped cases, absent/mismatched reports, failed task or no-write assertions, malformed logs and nonzero execution all prevent an automated-corpus pass. Another operating system must supply separately qualified network-denial behavior; the script refuses to silently drop the macOS boundary.

The runner records sampled generation-worker RSS, token budget and wall latency. It does not measure full application/GPU peak memory, manual correction time or native Wails interaction, and never marks performance or release qualification true. Use a separately scheduled quiet benchmark to evaluate performance; a functional run amid development activity is not controlled performance evidence.
