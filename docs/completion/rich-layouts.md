# Rich layouts and reusable source blocks

PARITY-001 adds/removes tab and column groups, creates supported text/code/diagram/equation/table/nested-layout children, moves existing page blocks (including managed attachments) into groups, duplicates subtrees and confirms content removal. Removing a group moves its children into another group instead of erasing them. The final group cannot be removed. Attachments can be created through the page attachment action and moved into the chosen group.

Rich proxies render the actual canonical node against the owning ProseMirror editor. Text marks, links, finite colors, technical source bytes, table cells and pre-merge evidence, attachment IDs and nested ownership are retained. Structural operations form separate undo units. Explicit parent changes at the same depth now produce canonical block.move commands. Existing kernel revision guards, page locks, ownership validation and cycle rejection remain authoritative.

Reusable content renders a read-only rich source subtree. Same-page references reflect the current editor draft. Remote references resolve an authorized readBlock and then the scoped source page to obtain its descendants; they do not scan or preload all workspace blocks. Workspace event cursor changes refresh remote sources. Missing or inaccessible sources retain an unavailable card and their canonical reference. Source edits happen through the source-page action; previews do not create independent editable copies. Defensive depth/cycle guards also bound rendering.

Verification: 38 frontend unit tests and all 15 editor browser regressions passed. Actual UI tests edit rich table cells, code and image controls inside layouts; create nested layouts; preserve content when removing groups; duplicate/remove/undo; update reusable previews and resolve a remote nested source. A real SQLite regression validates same-depth moves, source update/history recovery/reopen, export/reimport and remapped source/parent identities. Existing atomic cycle/ownership rejection tests pass. Browser fixture tests are separate from packaged desktop qualification.
