# Local support bundle — scoped source implementation

Source package `2e2a6b9c8e2d05391255261bf9ce3a5fc3a1361b` was integrated as `e481c6a7e602313be374785c49bc8ed73252ecad`. TRD-CONSTRAINT-020 now has a bounded local ZIP flow in Settings. Every save starts with an exact file preview, then a native destination dialog. There is no upload and no remote collection. All three native bindings reject a pending rollback child before consuming state or opening a dialog.

The default `metadata.json` contains only a fixed application label, validated build version/source revision/modified flag (unknown when absent or malformed), OS family/architecture, capture timestamp, numeric schema/index/content/job counts, allowlisted job kind/state and error-code aggregates, and passive capability flags. Unknown job labels/codes become `OTHER`; raw messages/payloads never enter the archive. Invalid/oversized error JSON also maps to `OTHER`. Build metadata does not include dependency paths or arbitrary settings. The bounded installed-manifest count checks presence and size, not weight integrity. No model loads or hardware probes run. Linux PDF reports `unavailable_containment`; microphone device/permission and other unprobed capabilities stay unknown.

Optional categories are off by default. Users select titles and/or supported page text from one to five live, non-archived pages. Text comprises directly stored rich text in paragraphs, headings, lists, quotes, callouts, toggles/toggle headings and code source, including collapsed content. Transcript-linked blocks are excluded by their canonical transcript provenance even though they are paragraph blocks. Linked tasks, reusable content, database properties, table cells, URLs/link targets, attachments, OCR, raw block JSON, history and unsupported blocks are not expanded; omitted blocks are counted. Page titles and text are separate consent categories. Selected page text or titles may themselves contain secrets: this flow does not promise automatic redaction of user-included content.

`selected-content.json` uses selection ordinals rather than workspace/page/block IDs. `manifest.json` records the actual categories, content file sizes and SHA-256 hashes, and exclusions. The exact UTF-8 file bytes shown in the preview are saved unchanged. The ZIP uses fixed member names. Raw application/job/import/model/search logs are not archived or invented.

Bounds: 4 KiB native selection request, five selected pages, at most 4096 blocks and 256 KiB source JSON per selected text page, 256 KiB combined selected output, 2 MiB archive, 15-second preparation deadline, five-minute preview/native operation lifetime, 30-second save deadline, and bounded 4096-entry/64 KiB-manifest passive model inventory. Preparation closes its read snapshot then checks live selected-page revisions/visibility, owner grant and closed state through the canonical writer and permission fence before publishing a preview. Save repeats those checks and expiry at final publication. The native token is single-use and bound to the exact current kernel; UI operation generations discard late results after cancel, discard, workspace change or unmount.

Save uses a private randomly named staging directory on the chosen destination volume and a 0600 file, followed by the audited no-replace regular-file publication primitive. Windows initial creation uses its protected owner/System DACL and publication refuses unsupported storage/ACLs without rewriting existing permissions. Existing destinations and symlink targets are never overwritten. Cancellation is checked during archive writing and before publication; cleanup failures are reported. An already-entered operating-system filesystem call is not interruptible by Go cancellation. The native save dialog retains its own Cancel control; programmatic cancellation prevents saving when it returns. This is not a transactional workspace backup or a guarantee against a hostile same-user process altering storage outside Trove's ownership contract.

Validation and exact source/evidence identities are in [the manifest](../../evidence/completion/support-bundle/manifest.json). Service tests plant secrets in titles, content, job payloads and raw errors; they inspect real ZIP members, exact consent bytes, stale/revoked previews, no-replace publication, transcript omission, bounds, cancellation and cleanup. Native binding tests cover opaque single-use review, changed workspace, picker cancellation and rollback entry guards. Browser fixtures exercise the actual Settings component, including late successful replies after cancellation. These are source/service/browser evidence on a developer Mac. A packaged native Settings/destination journey and Windows/Linux execution are not qualified by this package. GOV-003 and TRD-CONSTRAINT-020 remain partial for the broader redacted diagnostics system and release-level qualification.
