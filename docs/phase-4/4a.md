# Phase 4A — advanced editor, navigation and templates

Implemented in `frontend/src/editor`, `frontend/src/advanced`, and `internal/workspace/advanced_editor.go`.

- Native H4 uses the same rich-text codec and canonical identity as other headings, including the `#### ` input rule.
- Tables support rectangular merge and restore. Each merge retains full original canonical cell snapshots, including formatting and prior merge history. Restoring after editing retains the edited aggregate on the anchor cell and restores the other originals. Imported merges without original cell evidence remain preserved and cannot pretend to reconstruct missing cells. Backend validation rejects overlapping cells and out-of-bounds spans.
- Tabs and columns own canonical child blocks. The editor renders editable text in the layout, supports tab titles, column widths, and moving content among groups. Duplication allocates fresh subtree identities and remaps layout/synced references. Non-text children have readable cards; their source data remains canonical.
- Reusable blocks reference a canonical source, display its current text, and offer source navigation. The backend checks ownership, layout, and reusable-reference edges together for cycles. Source deletion leaves its reference intact with an unavailable card.
- Bookmarks have offline titles/descriptions. Embeds show escaped offline text in an empty-sandbox iframe with `default-src 'none'`; they perform no remote fetch and execute no imported HTML. Opening the source requires an explicit external link click.
- Breadcrumbs, H1–H4 table of contents, page/date mentions, block-link copy, Alt+Up/Down block selection, and exact replace-all are available. Replacement crosses rich-text formatting spans and preserves IDs, URLs, and opaque/raw/original-cell evidence.
- Page locks are persisted with a separate compare-and-swap revision. Only direct user calls may change them, and every canonical batch touching the locked page fails atomically, regardless of caller or origin. Unlocking requires current page and lock revisions.
- Saved button definitions produce a displayed canonical command proposal. Applying it uses the normal batch service, current revision guards, and the current caller's scope. Preview does not execute anything. The insertion UI supplies a rename-page action; the service accepts other validated canonical commands.
- The local template library stores immutable captured page bodies. Applying a template creates either a page or a record in an existing collection and remaps internal block identities. This is a **page-body/database-record template**, not a database schema clone. Existing collection defaults initialize record properties.
- Unlinked references match page-title occurrences in visible text. Related-page suggestions explain a shared lexical term; they do not claim semantic similarity. Results are limited to authorized, non-deleted pages.
- Search extraction includes offline cards, tab labels, bookmark text, and dates. Search never traverses raw or pre-merge evidence. Native snapshots, recovery, and portable manifest envelopes retain canonical structures; portable Markdown retains JSON fallbacks for structures without a dedicated renderer.

## Remaining limits

Layout editing currently offers two groups at insertion and moving existing child content between them; adding/deleting groups and fully rich nested atom editing in the layout are future controls. Reusable cards show source text; nested rich rendering is not duplicated. Search indexes the canonical source itself rather than expanding it into every reusable reference. Block-link copy stores a stable link; desktop deep-link routing into a specific block depends on the shell's link route. Page locks, template definitions and button definitions use additive workspace tables; native workspace backups retain them, and portable exports retain their definitions in the Phase 4 metadata manifest. Import reports explicitly preserve these definitions as inert evidence rather than enabling actions automatically. These limits prevent a claim that every Phase 4A exit-gate scenario is fully qualified.
