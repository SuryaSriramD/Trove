# Phase 4D — capture and external indexes

`CapturePanel` supports manual share/paste and the bundled Manifest V3 browser clipper. The clipper pairs through an explicitly started, authenticated loopback listener and creates durable drafts for native owner review. Article, selected text, URL-only clips and explicitly acquired PNG/JPEG/GIF images can be saved to Inbox or beneath an approved page. Destination permissions and revision are checked again at final save. Restarting the app or switching workspace revokes the session; previously received drafts remain. HTML is sanitized through the canonical adapter and source/channel/time/image evidence is retained. Remote resources are never fetched implicitly. See [browser clipper implementation and qualification](../completion/browser-clipper.md) and [installation instructions](../../browser-clipper/README.md).

The macOS screenshot action invokes only the OS interactive region picker after the user presses Capture screenshot. It yields a regular-file selection handle for the existing reviewed import path. The screenshot is not indexed by OCR or vision. Other platforms direct users to import an OS screenshot. OS Screen Recording permission and user cancellation remain visible native outcomes; continuous screen capture is absent.

## Reference-only filesystem and repository indexing

Only `App.PickIndexRoot` can authorize a native folder path. Renderer dispatch takes an opaque root ID, never an arbitrary path. Grants require the direct workspace owner. Approval persists the directory's canonical path and device/inode identity. Every scan rechecks that identity and opens an `os.Root`; root replacement, revoked approval and symlink escapes are denied. Canonical workspace storage cannot itself be approved as an external root.

Approved roots are polled every 30 seconds while the workspace is open, with a 30-second deadline per root; the UI also provides Refresh index. The watcher is canceled with the app job lifecycle and does not run when Trove is closed. Repeated unchanged diagnostics are suppressed. A successful scan publishes all derived changes atomically; a failed/over-budget traversal does not falsely tombstone unseen files. Missing/replaced roots invalidate indexed snippets while preserving reference identities.

Default exclusions include `.env*`, SSH/cloud credential directories, private keys, `.npmrc`, `.netrc`, `.pypirc`, Git credentials, common build/dependency directories, database/binary/media files and symlinks. Private-key markers and invalid UTF-8/NUL content are also excluded. Nested `.gitignore` and `.troveignore` support comments, glob patterns, `**`, directory rules and ordered negation. Default secret exclusions cannot be negated. As with Git traversal, an ignored directory is not entered to find nested re-inclusions. This is a documented bounded ignore implementation, not a claim to reproduce every Git pattern escape extension.

Limits are 10,000 regular files, 128 MiB/scan, 4 MiB/file and 64 levels. Supported language labels include Go, Python, JavaScript/TypeScript, Rust, Java, C/C++, Ruby, Swift and Markdown. The chunker recognizes declaration/heading boundaries and retains line ranges and symbols, with an 80-line/8 KiB target; arbitrary code is never executed. This lightweight scanner does not claim a language-server-quality AST.

The derived store tracks stable source ID, root, path, device/inode, content hash, extractor version, timestamp and present/missing state. Moves reuse source identity, deletes become tombstones, and `external_page_references` survive both. Indexed snippets are removed on deletion or revocation. External files are never copied to the managed asset store by indexing. Explicit folder/document import is the separate copy path.

Queries are `index.roots`, `index.scan`, `index.entries`, `index.search`, `index.revoke`, and `index.reference`. External snippet search is owner-scoped and only includes approved, present sources. All database writes stay in the workspace service. There is no renderer-controlled shell command or filesystem read.

## Validation

`index_external_test.go` checks rejection of unapproved/revoked/replaced roots, workspace-storage denial, secret/binary/symlink/ignore exclusions, language chunks, source identity across renames, missing-file tombstones and preservation of linked page references. Capture and HTML tests in `import_expanded_test.go` verify the permission/review path.

Native screenshot UI interaction and platform variants are not claimed by automated unit tests. OCR/vision remains P2.
