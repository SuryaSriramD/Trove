# Phase 1E — Native runtimes, models, and packaging

The product-native layer is `internal/native`, backed by three bundled arm64 executables built by `scripts/build-native.py`. The desktop owner packages `build/native` at `Trove.app/Contents/Resources/native` and initializes `NewManager(modelRoot)` then `NewSupervisor(bundlePath, manager)`. There is no end-user Go, Node, Python, Ollama, Homebrew, or database-server dependency.

## Implemented interfaces

- `Manager.Acquire(ctx, pack, progress)` downloads only after an explicit catalogue action. `Manager.Import(ctx, pack, reader, progress)` accepts a native-picker opened file. Both enforce declared size, SHA-256, model magic, role, exact runtime commit, arm64 compatibility, context/dimension limits, and memory estimate. `LoadCatalog(bundle)` loads the pinned `models/catalog.json`. `List` distinguishes ready/corrupt/acquiring/interrupted. `Remove` rejects leased or acquiring packs.
- Acquisition keeps `.part` and atomically synced manifest/ETag metadata. A restarted manager resumes with Range and If-Range; a server returning 200 restarts safely. A complete file is accepted only after its final hash matches. Publication uses a rename followed by a synced manifest; a crash between those steps is reconciled on the next explicit acquisition.
- `Supervisor.Run(ctx, Request, onEvent)` takes `contracts.JobsWorkerRequest` and approved `Input` file descriptors. `OpenInput` hashes a trusted descriptor. Run stages private read-only snapshots and rechecks their hashes before launching. It validates the shared request/output/result schemas and rejects changed input bytes, wrong worker/build/version, sequence/request/lease mismatch, duplicate terminal events, invalid result hashes, embedding shape/location mismatch, and transcript identity/time mismatch.
- `Supervisor.Capture(ctx, CaptureRequest, stagingFile, onEvent)` captures PCM float32 mono 16 kHz through AVFoundation. An explicit `RequestPermission` action is mandatory. Synthetic qualification never opens the microphone or prompts. Captured buffers flush to the service-owned staging file; cancellation retains recorded bytes. The shell must preserve that staging file and commit approved attachments through workspace services.
- `Scheduler.Enter` admits one heavy native job; recording cancels lower-priority work and waits for confirmed cleanup. `SetEditing(true)` stops background work and blocks new background admissions. Chat precedes transcription and background indexing. Every process unloads its model on completion, so there are no indefinitely resident idle models.

The durable job service remains the owner of job leases, retries, checkpoints, and canonical result commits. It passes cancellation through the context and rechecks the live lease and source revisions when committing returned proposals. Native workers never receive the SQLite database or call a mutation service. The desktop/kernel integration owns workspace preservation and job-recovery acceptance.

## Worker transport and resource bounds

The inference protocol is the Phase 0 `jobs.schema.json` protocol: a 4-byte big-endian length plus 1–1,048,576 bytes UTF-8 JSON, 64 KiB read/write chunks, exact pinned `hello`, strictly increasing sequence from zero, tokens/progress, and one result/error/cancelled terminal event. stdout is exclusively protocol data. OS pipes provide bounded backpressure without an unbounded user-space token queue. A separate control pipe stays available during output backpressure. Each helper is a one-request process; the durable job receipt is the authoritative acknowledgement after service commit.

Descriptor mapping: fd 3 cancellation, fd 4 supervisor-owned result file, fd 5 verified model, fd 6 input metadata, and fd 7 speech PCM when present. `InputMetadata` in `internal/native/inputs.go` is private descriptor format version 1 (`schemaVersion:1`); unknown keys fail. Generation supplies `text`, `contextTokens`, `gpuLayers` (0 CPU or -1 Metal); embeddings supply `texts`, canonical `locations`, `contextTokens`, and `gpuLayers`; transcription supplies `meetingId`, reserved `segmentIds` (`segmentId`/`blockId`), language, and `useGPU`. Transcript source audio is finite float32 PCM mono 16 kHz. Input batches contain at most 256 source locations or reserved segments; longer work is split into durable job units by the caller.

The microphone control protocol is independently versioned v1: record request with requestId, durationMs, maxBytes, requestPermission, synthetic; hello identifies microphone/trove-microphone-v1/arm64; progress and result carry actual flushed byte counts, sample rate, channels, and format. The parent validates sequence and request identity. `NSMicrophoneUsageDescription` and the audio-input entitlement belong in the app bundle; no permission request occurs on startup.

Requests cap threads at 8, wall time at 2 hours, output at 64 MiB, and tokens at 32,768, then intersect with pack context and available memory (at most 16 GiB and half physical RAM less a 2 GiB reserve). RSS and result size are sampled every 250 ms. Cancellation first writes the control frame, sends process-group TERM after 2 seconds, then KILL after 5; every process is reaped. Diagnostics retain only a bounded 256 KiB in-memory ring and are not exposed as user content. Helpers use private working directories, minimal environments, native descriptors, and executable hash checks; this is supervision, not a claim of OS-enforced filesystem/network containment.

## Models and licensing

`native/models/catalog.json` separates chat, embedding, and speech packs. Exact archive revisions, SHA-256, sizes, roles, formats, dimensions, memory estimates, and license URLs are included. `provenance.json` records original publisher license declarations. TinyStories 15M Q4 is deliberately marked a runtime qualification pack, not a general assistant. BGE-small produces 384-dimensional embeddings. Whisper tiny English transcribes the public-domain JFK fixture shipped with pinned whisper.cpp. Models remain optional downloads outside the application bundle. Production assistant quality and multilingual speech quality require later model selection/evaluation.

## Reproduce

```sh
python3 scripts/build-native.py
python3 scripts/acquire-test-models.py
TROVE_NATIVE_INTEGRATION=1 GOCACHE=/private/tmp/trove-phase0-tools/go-cache GOMODCACHE=/private/tmp/trove-phase0-tools/go-mod /private/tmp/trove-phase0-tools/go/bin/go test -race -v ./internal/native
python3 scripts/build-desktop.py
```

The builder verifies pinned source archives and extracted source bytes, builds isolated Phase 1 static libraries with embedded Metal shaders, links C++ wrappers, builds the Swift helper, signs helpers ad hoc, and records post-signing hashes. Re-signing helpers changes hashes; regenerate their manifest before signing the outer bundle. Do not use deep re-signing after manifest generation. The qualification target and deployment minimum are macOS 27 / arm64; older macOS versions require a separate rebuild and qualification.

Evidence: `evidence/phase1-native-smoke.json` records actual CPU text generation, 384-dimensional inference, timestamped real speech transcription, and synthetic capture. `evidence/phase1-native-failure.json` records cooperative cancellation, a deliberately killed real inference worker, and subsequent Metal inference. Unit/race tests cover corrupt models, incompatible runtime, in-use removal, interrupted HTTPS acquisition/restart/resume, malformed frames, and resource priorities. The desktop package gate separately verifies persistence across process restart and helper launch from the actual bundle.

## Acceptance boundaries still requiring external evidence

`security find-identity -v -p codesigning` returned **0 valid identities** on this host. Development helpers/app are ad-hoc signed; Developer ID signing, notarization, Gatekeeper distribution acceptance, and installation on a separate clean Mac are **unverified**. Codesign and dependency inspection establish local package integrity, not those distribution claims. Actual microphone permission/capture was not exercised without an explicit user recording action; synthetic capture verifies the pipeline without collecting private audio. Minimum-OS, hard sandbox containment, thermal stress, sustained recording interruption, and production-model quality remain separate qualification items. These are recorded as pending rather than counted as completed checks.
