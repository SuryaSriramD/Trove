# Phase 1A — workspace kernel, jobs, and permissions

Implemented and verified on macOS Apple Silicon. `internal/workspace` is the Go authority for canonical mutations; the packaged Wails facade delegates to its typed `contracts.WorkspaceServices` interface and validated JSON adapter. Database/task and file/history handlers from 1C/1D participate in the same transactions.

## Storage and services

Create/Open maintain persistent UUIDv7 workspace identity and one active owner through an OS advisory lock. Migrations execute atomically, preserve a database snapshot before upgrading an existing canonical schema, and recover after an interrupted attempt. Database and lock-file symlinks are rejected. SQLite enables foreign keys, WAL, and a five-second busy timeout; one `BEGIN IMMEDIATE` writer has a 128-request admission bound, and eight deferred reader connections serve consistent snapshots.

Pages, blocks, links, records, collections, views, tasks, files, and history use one service mutation boundary. Every explicit existing target is revision guarded; stale requests return conflicts. Page/record aggregate revisions remain equal. Registry validation and SQL constraints reject malformed or inconsistent mutations atomically. Page snapshots retain recovery metadata, while normal historical reads return the canonical page DTO. Archive timestamps survive rename and restoration. Restores create new revisions and carry `restore` event origin.

Server-issued grants authenticate actor, origin, workspace, scope, and policy. Project grants use explicit ownership/membership/pins/exclusions; page-tree ancestry does not expand retrieval authority. Exact proposal approvals bind canonical hashes and are consumed once. Nullable removal intent survives typed round trips and affects approval hashes. Idempotency receipts, history, committed events, snapshots, and result-unit receipts commit with content. Durable cancellation receipts resolve the race between cancellation and commit without falsely reporting rollback. Slow event listeners reconnect and catch up from durable cursors; tombstones survive catch-up.

## Persistent workers

Jobs persist their payload, state, attempt budget, progress, lease, original delegation, and source revisions. Only an explicit authenticated user action can delegate a job in this release; AI/external/import principals cannot bypass approval by enqueueing one. Revoking the originating grant revokes its delegation and cancels queued or running work. Approved delegations survive application restart; current source permissions and revisions are rechecked before results commit.

Workers claim a fresh lease, report monotonic progress, and run outside SQLite. Retry attempts are bounded and delayed; invalid input and unavailable capabilities fail explicitly. Cancellation and shutdown stop new work, cancel supervised native processes, and fence late results. Restart recovers interrupted attempts and cancellation requests. One failed handler does not stop later jobs.

`internal/workers.Run` connects the job runner to bundled native supervision. Transcription reads an authorized file ID, converts bounded 16 kHz mono PCM WAV input in temporary storage, uses a verified speech pack and read-only descriptors, reserves stable segment/block IDs, then atomically commits the transcript, source revisions, result receipt, and successful job state. Retries cannot duplicate a committed result. Citation resolution checks page revision, meeting, segment, block, and transcript timestamp bounds. Backup jobs use opaque owner-bound native destination capabilities, produce verified SQLite-plus-assets backups, and reconcile a completed backup after a lost acknowledgement. Other job operations without an installed implementation fail explicitly.

## Verification

The final integrated run passed **47 workspace tests, 2 worker tests, and 5 contract tests**, all with Go's race detector and with the real native transcription test enabled. No tests were skipped. Coverage includes restart persistence, exclusive ownership, migration fault rollback, foreign keys/WAL, concurrent stale writers, invalid requests, scope and approval denial, idempotency, cancellation races, durable event tombstones, bounded retries, lease fencing, source conflicts, shutdown cleanup, native transcription, backup recovery, and the 1C/1D service acceptance fixtures.
