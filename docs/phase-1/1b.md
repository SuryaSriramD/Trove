# 1B — Desktop shell and canonical editor

The production frontend is `frontend/`, built with the baseline's pinned React 19, TypeScript 7, Vite 8 and Tiptap 3. It communicates only with `window.go.main.App` through the typed adapter in `frontend/src/api.ts`. There is no production browser database or in-memory content fallback. Missing IPC displays the workspace connection surface. Local storage holds presentation preferences (tabs, favorites, recent IDs, theme), never canonical content.

## Implemented

- Home, Inbox (unfiled pages), Pages, Tasks, Meetings, Search, Import, Settings; tree navigation, favorites, recent pages, open tabs, breadcrumbs, back/forward, quick switcher and page-reference backlinks.
- Create, rename, move/nest, archive/unarchive, trash, icon and immutable file-backed cover. Native file picker, native dropped-file events, and bounded clipboard/browser file staging use prepared file handles and canonical attachment commands.
- Tiptap rich text with bold/italic/underline/strike/code/link marks; H1–H3 creation plus H4 preservation; nested bullet/numbered lists; canonical task-reference nodes; toggles; quotes; callouts; dividers; source-editable highlighted code; strict Mermaid SVG; KaTeX inline/display rendering; simple editable tables; images, file links, PDF, audio and video.
- Insert/slash menu, heading/list/quote Markdown rules, native ProseMirror block dragging, formatting transforms, duplication, find, undo/redo. Existing block identity survives editing and moving. New/split/pasted block identities come from kernel allocation.
- Imported merged table cells and `preMergeCells`, content-tab identities/child references, unknown structures and raw fallback payloads survive the editor codec. Unknown payloads display readable fallback and expandable retained JSON. Imported structures are not normalized into plain text.
- Saves produce minimal canonical atomic batches with decimal-string revision guards, plus affected record/collection guards. ID allocation precedes insertion. Navigating away awaits outstanding saves; a rejected save keeps the editor draft visible. Conflicts show the issue and permit copying the retained draft JSON. Committed events refresh shell projections. Editing signals native resource scheduling.
- Settings exposes verified model catalogue role, size, memory estimate and license; native availability; download/resume/import/cancel/remove and progress events. Catalogue authority and verification remain in Go.

Task creation/completion and database views integrate the shared 1C module; there is no local checkbox state in todo data. The only todo payload is `taskRecordId`. The Import surface accurately distinguishes immutable source attachment from the later structured importer/re-import review. Meetings provides meeting-page navigation and notes creation; transcription/recording work belongs to the native service path.

Use Node from the installed baseline, and install `frontend/pnpm-lock.yaml` with frozen lockfile. The large dependency store may be put on a local fast volume without changing the lockfile. At implementation time `frontend/node_modules` points to `/private/tmp/trove-phase1-frontend/node_modules`; the symlink is ignored and is not a required deployment path.

- `node frontend/node_modules/typescript/bin/tsc --project frontend/tsconfig.json --noEmit`
- `node --experimental-strip-types --test frontend/tests/codec.test.ts`
- From `frontend`: `node node_modules/vite/bin/vite.js build`
- Start Vite on `127.0.0.1:4173`; from `frontend`: `node node_modules/@playwright/test/cli.js test`. The config uses installed macOS Chrome; set `CHROME_PATH` for another installation. Tests inject an explicitly test-only Wails contract adapter and persist its fixture across reload. They never supply a production content fallback.

`evidence/phase1-browser-tests.json` records browser results. `evidence/phase1-home.png` and `evidence/phase1-editor.png` were inspected for layout. Browser scenarios cover navigation and title save, mixed-block copy/paste and new identities, Devanagari/Telugu/CJK/Arabic/emoji text, composition events, undo/redo, save/reopen, H4/merged-cell/raw preservation, real code/Mermaid/KaTeX rendering, Markdown rules, duplication and accessibility-tree/keyboard semantics. Codec tests separately cover raw structures, content tabs, parentage, reparent commands, marks/links/Unicode, task references and child-first deletion.

## Qualification boundaries

Browser tests prove renderer behavior against the contract adapter. The root integration gate must separately prove the real Go SQLite/file bridge and packaged restart. Synthetic `compositionstart/update/end` and Unicode insertion do not prove macOS input-method candidate selection. Accessibility-tree names, heading levels, toolbar semantics and focus traversal do not prove VoiceOver speech/navigation in WKWebView. Native IME and VoiceOver qualification remain explicitly unverified until exercised on the packaged app. Never mark those requirements verified using the browser screenshots or synthetic events alone.

## Final integration corrections

Attachment picker, native drop, and multi-file paste/drop share a serialized renderer queue. Each attachment flushes the active editor, fetches the current authoritative snapshot, and applies the next file with fresh revisions. Workspace switching waits for queued attachments. The slash-menu attachment path shares that queue and refreshes the editor after committing. Add-block moves focus synchronously to the new text position; the browser test asserts editor focus before typing Markdown. Final five browser scenarios passed after these corrections. Native packaged workspace selection was exercised successfully against the integration fixture; see `evidence/phase1/native-workspace-picker.json`. The transient disabled Open button cleared after native directory validation, requiring no picker replacement.
